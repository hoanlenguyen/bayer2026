# DEMO-POL-001 · Production dashboard ownership · Revision 1

Synthetic demo note written for AnalytIQ. It is not a company policy.

Issued by: AnalytIQ demo content · Accountable team: BI Governance (demo) · Effective from 2026-01-01

## 1. Scope
This note applies to dashboards that the BI department has explicitly mapped to it and that sit in a production workspace.

## 2. Ownership handover
When accountability for a mapped dashboard changes, the current owner records the incoming accountable person in the governance record before the handover takes place.
